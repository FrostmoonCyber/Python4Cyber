# 📂 01_Fundamentals: Python Core for Security

This section focuses on mastering Python's basic syntax and applying it to security-related logic. Each script here represents a step toward building more complex automation tools.

### 🎯 Learning Objectives
* **User Input & Sanitization:** Safely capturing target data (IPs, domains).
* **Data Types:** Working with strings and f-strings for clean reporting.
* **Flow Control:** Implementing basic `if/else` logic to handle errors and empty inputs.

### 🛠️ Scripts in this folder
* **[01_ip_format_checker.py](./01_ip_format_checker.py):** Validates IPv4 target addresses before network operations.
* **[01_file_integrity_guard.py](./01_file_integrity_guard.py):** Backs up files and computes SHA-256 hashes to monitor integrity.
* **[01_log_parser_basics.py](./01_log_parser_basics.py):** Parses authentication logs to identify and count failed login attempts.
* **[01_port_scanner_basics.py](./01_port_scanner_basics.py):** Checks TCP socket connections to identify open ports on a target host.
